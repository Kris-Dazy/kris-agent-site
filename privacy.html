Privacy policy

Last updated 22 October 2026

Who uses this app

kris-agent is used only by its owner, with the owner's own Google accounts. It is not available to anyone else.

What data it accesses

With the owner's permission, it reads and changes files, emails and calendar events in the owner's own Google accounts, only to carry out tasks the owner asks for.

Where data goes

Data stays on the owner's own computer. It is not sold, shared with third parties or used for advertising. Sign-in tokens are stored locally and never published.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Via the owner's GitHub profile: github.com/Kris-Dazy.
